Business Job Market Rumors is a full-stack JavaScript web application that I created in 2023. 

- The project Used MongoDB, Express.js, React.js, Node.js stack and integrated Tailwind CSS for rapid UI styling. Common social media functionalities are available with Role-based access control (RBAC).

- Extra features include context-based authentication using JWT, partial IP disclosure using GeoLite2 and automated content moderation using Flask app to operates as a zero-shot classification pipeline using BART Large MNLI.

- This project was deployed on Azure App Service with MongoDB hosted on Azure Cosmos DB.
